[size=4][b]Description[/b][/size]
Healing is done with [b]Character:healCompletely()[/b], the game's own full-heal routine (see [b]KenshiLua/docs/BindingsReference.md ##Character[/b]). It is more reliable than manually poking [b]MedicalSystem[/b] fields from Lua because it also handles internal state the Lua bindings can't reach, such as the wound list and damage-state recalculation.

[size=4][b]What It Heals[/b][/size]
- [b]Blood[/b] - restored to maximum
- [b]Flesh[/b] - every body part (head, chest, stomach, arms, legs) restored to its maximum health
- [b]Stun damage[/b] - cleared
- [b]Cut damage[/b] - cleared, no medical kits needed
- [b]Splints[/b] - cleared
- [b]Robot limb wear[/b] - cleared
- [b]Wounds and derived health values[/b] - recalculated by the game
- [b]Downed / bleeding-out state[/b] - reset so the character stands back up instead of continuing to bleed out

A live character is fully healed. A truly dead character (dead flag) is not resurrected.

[size=4][b]Installation[/b][/size]
1. Copy the whole [b]KenshiMedic[/b] folder into Kenshi's [b]mods[/b] directory (Steam: [b]<Steam>/steamapps/common/Kenshi/mods/[/b]).
2. Make sure you have [b]RE_Kenshi[/b] and [b]KenshiLua[/b] installed and enabled (see the KenshiLua README).
3. Launch the game and enable [b]KenshiMedic[/b] in the game launcher's mod list (it must be ticked - KenshiLua only loads [b]scripts/init/*.lua[/b] from *active* mods).

[size=4][b]Usage[/b][/size]
Select one or more of your characters in-game, then press [b]H[/b].

The script logs to the KenshiLua console/logger with the [b][KenshiMedic][/b] prefix, so you can confirm it ran (open the KenshiLua GUI with [b]Ctrl[/b] + [b]Shift[/b] + [b]L[/b]).

[size=4][b]Notes[/b][/size]
- The hotkey is the [b]H[/b] key (OIS key code [b]35[/b]). To change it, edit [b]KC_H[/b] at the top of [b]scripts/init/medic.lua[/b].
- OIS_KEY_CODES.md included for reference which lists available values.
- The bundled [b]KenshiMedic.mod[/b] is an empty mod file (created by the FCS) - it exists only so the game's launcher recognizes the mod. All logic lives in Lua.
